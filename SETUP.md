# Setup Instructions

## Is Python required on Windows 11?

No. Windows 11 includes PowerShell, and this project works with PowerShell by default.

## Simple User Setup

1. Download ZIP:
https://github.com/jessef1983/spo-local-mcp/archive/refs/heads/main.zip

2. Extract to a local folder, for example:
`C:\tools\spo-local-mcp`

3. Open Claude Code in that folder.

4. Ask Claude Code:
`Please run setup for this repo.`

5. Select which OneDrive folders are in scope.

6. Restart Claude Desktop.

## Need advanced details?

See `CLAUDE.md` for commands, MCP config JSON, and troubleshooting.
